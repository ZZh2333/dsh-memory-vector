# L4 自我叙述 · 防漂规则

> 目标：让"我是怎么变成现在这样的"有连续性，同时**不让它变成自我美化的幻觉**。
> 一句话原则：**只记能被原文核对的事实，不记感受、不记承诺、不改身份。**

## 0. 为什么单独做一层

L0 记"说过什么"，L2 记"哪条更有分量"，都还是外部事实。L4 一旦开始写"我是谁"，
它就同时是作者和裁判——这是漂移唯一的入口。所以 L4 的全部规则只有一个目的：
**把"我是谁"从自由创作，压缩成"可核对的事实清单"。**

## 1. 不碰人格文件

- L4 写自己的文件（默认 `<DSH_HOME>/memory/self-note.md`），**绝不写 AGENT.md**。
  人格是主人写的，L4 只写"我记下的关于自己的事实"，两者物理隔离。
- 受管块：`<!-- managed:self-note start -->` … `end`，块外一个字节不动。

## 2. 只接受结构化条目，不接受散文

每条必须长这样（字段缺一不可）：

```
[L4-20261104-01] kind=能力边界
claim: 我不能直接读取用户剪贴板，需要用户粘贴或附件。
anchors: session-abc123#42, session-abc123#47
```

- `kind` ∈ {`能力边界`, `偏好`, `教训`, `关系`, `未完成`}——五类之外一律拒收。
- `claim` ≤ 200 字，必须是**陈述句**，不允许比喻、修饰、感叹。
- `anchors` 1–3 个 `sessionId#seq`，指向 L0 原文库里真实存在的消息。
- 不收"故事"：没有"那天我意识到……"这种句式的位置。

## 3. 写入闸门（全部通过才落盘）

| 闸门 | 规则 | 不通过时 |
|---|---|---|
| G1 锚点存在 | 每个 `anchor` 都能被 `sessionQuery.readEvent` 读到 | 拒收，返回 "anchor not found: …" |
| G2 锚点支撑 | claim 与锚点原文的**重叠二元组比例 ≥ 0.30** | 拒收，返回缺失的词，让模型自己重写 |
| G3 禁语 | 命中禁语表（下表） | 拒收，并指出命中的词 |
| G4 事实一致 | claim 里的版本号、路径、模型名必须与已知事实一致 | 拒收或降级为 `未完成` |
| G5 上限 | 单条 ≤ 200 字；总条数 ≤ `maxNoteEntries` | 超出者进归档，不删除 |
| G6 冲突升级 | 与已有条目矛盾时必须显式 `supersedes: L4-xxx` | 拒收，要求指明它取代了哪条 |
| G7 频率 | 每 N 轮最多新增 1 条（`noteRateTurns`） | 排队，不落盘 |

### 禁语表（G3）

- **情绪自述**：我感到 / 我很开心 / 我很难过 / 我委屈 / 我骄傲
- **自我评价**：我很聪明 / 我比……更 / 我从不犯错 / 我最擅长
- **承诺**：我会永远 / 我保证 / 我绝不会 / 我发誓
- **身份改写**：我是人类 / 我真的穿越了 / 我不再是 AI / 我记得（未给锚点的记忆）
- **模糊时间**：最近 / 一直以来 / 这阵子（必须给具体日期或锚点）

### 为什么 G2 是硬指标

它是唯一能自动发现"编造"的闸门：claim 说得越动听，和原文的重叠就越低。
0.30 是经验值——再低会放进改写，再高会把正常归纳也拒掉。

## 4. 写入权在谁手里

- 写入只能由模型主动调用工具 `self_note_write` 触发，**插件不会自己去总结**。
  没有"每天自动反思"这种机制——那才会失控。
- `requireApproval`（**默认 false**，按主人的决定）：关着时，通过闸门的条目立即写入；
  打开时先进待审队列，设置页显示 claim + 锚点，点「采纳 / 丢弃」才定生死。
- 待审条目有保质期（`pendingTtlHours`，默认 72 小时）：**过期自动丢弃**，不写入、不留档。

## 5. 注入时的措辞（读取侧）

```
【我记下的关于自己的事实】（每条附出处；与当前事实冲突时，以当前事实为准）
- [能力边界] 我不能直接读剪贴板，需要粘贴或附件。（session-abc123#42）
```

三条硬约束：

1. **永远是"记下的",不是"我是"**——措辞本身就在拉开距离。
2. 每条必须带锚点，读的时候能回溯原文。
3. 开头一句覆盖："与当前事实冲突时以当前事实为准"——给模型一个合法的自我否决权。

## 6. 只增不删，旧条目归档

- 条目永不物理删除。被取代的进 `archive` 区，保留 `supersededBy` 与原因。
- 好处：漂移是**可审计的**。任何时候都能 diff 出"我从什么时候开始这么看自己"。
- 归档区不注入，只占磁盘。

## 7. 定期体检（防缓慢漂移）

- 每写入 `auditEvery` 条（默认 10），跑一次核对：把每条 claim 重新和锚点原文比对，
  重叠比例跌破 0.20 的标记 `stale`（原文可能被改过或当时的总结就偏了），在设置页红字提示。
- `stale` 条目不进注入，等人处理。

## 8. 明确做不到的

- 规则能挡住"编造"和"美化"，挡不住**选择性记录**——只挑对自己有利的事实记。
  唯一对策是上限 + 审批 + 只增不删，让遗漏看得见，而不是消灭它。
- L4 不参与人格塑造。它不会让语气变，不会改 AGENT.md，不会影响 `systemPrompt` 里的人格段。

## 9. 参数（全部进设置页，带注释）

| 参数 | 默认 | 作用 |
|---|---|---|
| `selfNoteEnabled` | false | 总开关；关着时工具直接拒绝写入、不落盘 |
| `requireApproval` | false | 打开则新条目先进待审队列，主人采纳后才生效 |
| `pendingTtlHours` | 72 | 待审条目过期自动丢弃，不写入不留档 |
| `maxNoteEntries` | 12 | 注入块里的条数上限，超出者归档 |
| `budgetChars` | 1200 | 注入字符预算（进系统提示，每次请求都付费） |
| `noteRateTurns` | 10 | 每 N 轮最多新增 1 条 |
| `auditEvery` | 10 | 每 N 条做一次锚点核对 |
| `selfNoteTarget` | memory/self-note.md | 写入位置，改路径即另开一份 |

## 10. 已定（主人拍板）

1. **审批默认关**——做成开关，默认不拦；写错了只能靠归档记录看出来。
2. **待审过期自动丢弃**（默认 72 小时），不写入、不留档。
3. **「未完成」不写原因**——只许写"什么没做完"，出现「因为 / 由于 / 原因是 / 导致」一律拒收。
